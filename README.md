# The Indian Watch Co. · Samrat Tourbillon

Concept website for a college brand project. Single page, plain HTML, CSS and JavaScript, no build step.

## Run it
Open `index.html` in a browser, or serve the folder: `python3 -m http.server`.

## Publish on GitHub Pages
1. Create a repository and upload `index.html`, `README.md` and the `assets` folder to the main branch.
2. Settings > Pages > Source: Deploy from a branch > `main` / root.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/`.

## Interactions
- Live watch on Indian Standard Time. Tilt it with the mouse. Pull the crown, drag the dial to set your own time.
- Sundial of the Vrihat Samrat Yantra. Drag the sun to move the shadow.
- Anatomy hotspots on the Samrat.
- Tourbillon cage you can spin, with inertia.
- The 80 registry with a live caseback engraving preview. The form is a demo and sends nothing.
- Teakwood vault that opens when you turn the key.
- Campaign gallery with drag scrolling and a lightbox.
- World clocks that jump to the launch moment.

The Indian Watch Co. and the Samrat Tourbillon are student concepts. Nothing here is for sale.
